# Status feature module

Extraction target for the Updates/Status experience.

Planned modules:
- `StatusCard.tsx`: horizontal story card with visible preview.
- `StatusProgress.tsx`: story progress indicator.
- `statusExpiry.ts`: 24-hour expiry calculation and filtering.
- `UpdatesSections.tsx`: Status before Channels ordering.

Compatibility rule: preserve existing status upload, view, like and view-count behavior while changing presentation and ordering.
